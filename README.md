# 🎬 Movie Review Sentiment Analyzer

An end-to-end NLP and Machine Learning web application that analyzes and classifies movie reviews as **Positive** or **Negative**.

## 🚀 Tech Stack
- **Language:** Python
- **Machine Learning:** Scikit-Learn (Logistic Regression, TF-IDF Vectorization)
- **Deployment:** Streamlit
- **Model Serialization:** Joblib

## 📊 Dataset
Trained on the **IMDB 50K Movie Reviews Dataset** using TF-IDF feature extraction to convert text into numerical feature representations.
